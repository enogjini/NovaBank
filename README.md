# NovaBank 🏦
A lightweight, local bank management desktop application built with C++ and the Win32 API.

## Features
* **Client Login:** Check balances, add funds, withdraw, and transfer money between accounts.
* **Admin Panel:** View all registered users and manage accounts (delete/refresh).
* **Persistent Storage:** All data is saved locally in `accounts.txt`.

## How to Run (For Other Machines)
1. Go to the **Releases** section on the right.
2. Download `NovaBank.exe`.
3. **Note:** Since this is an unsigned .exe, Windows may show a "Protected your PC" warning. Click **More Info** -> **Run Anyway**.
4. Ensure `accounts.txt` is in the same folder as the `.exe` for data saving.

## Default Admin Credentials
* **User:** `admin`
* **Password:** `admin`
